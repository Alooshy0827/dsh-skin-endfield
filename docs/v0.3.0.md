# v0.3.0：HarmonyOS Sans 鸿蒙字体

配色：沿用纸白 / 炭黑 / 酸黄，不调整终末地装饰层。
字体：界面与启动字标改为 HarmonyOS Sans SC，代码区保留原生等宽字体。
动效：沿用 1 秒启动与 140–260 ms 交互动效，支持减少动效。

最新实测适配 DSH **0.2.1-rc.5**，平台为 macOS 桌面版。

## 实现

通过 DSH 的 `--dsw-font-family` 主题令牌替换界面字体。没有改动字号、行高、间距、主色、宿主布局或交互逻辑。停用插件时令牌和字体样式一并撤销。

使用[华为官方字体包](https://developer.huawei.com/images/download/general/HarmonyOS-Sans.zip)中未修改的 HarmonyOS Sans SC Regular / Bold，以内嵌 TTF 离线加载。两份字体原始大小合计约 15.7 MiB，使客户端资源增加至约 21 MiB；不依赖系统安装字体或运行时网络。字体采用 HarmonyOS Sans Fonts License Agreement，非 OFL，许可随插件一起保留。插件说明包含字体使用声明。

## 验证

- 8 项生命周期与故障测试通过，包含 100 次启停、减少动效、异常清理。
- 174 份 DSH 参考文件和原应用归档哈希保持一致。
- 隔离实例实测中英文输入与清除、主题切换、设置开关、皮肤启停恢复和冷启动；无浏览器警告或错误。
- 对比主界面 26、插件页 33、设置页 47 个控件；布局容器、控件高度和纵向位置保持一致，没有页面横向溢出。两个文本按钮缩窄 0.39 / 3.76 px，两个行内字号步进按钮横坐标改变 0.109 px，完整记录保留。
- 发布检查直接读取原始布局证据，字体调整仅允许小于等于 4 px 的文本宽度和 0.125 px 的横向行内偏差；容器、纵向位置、高度和控件名称仍须严格相等。
- 桌面插件管理器安装冻结包并完整退出重开，验证启停、输入和主题设置。没有发送模型消息。

## 安装与回退

卸载旧皮肤，在 DSH 插件管理器添加解压后的 `dsh-skin-local-0.3.0` 绝对路径，启用后完整退出并重新打开 DSH，以刷新模块缓存。停用即可恢复原外观；v0.2.1 冻结包保留，可重新安装。

本次验证覆盖上述版本与操作，不代表所有第三方插件组合或后续 DSH 版本均已验证。
