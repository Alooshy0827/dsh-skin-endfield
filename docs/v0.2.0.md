# Endfield 皮肤 v0.2.0

适配并实测 **DeepSeek Harness Desktop 0.2.1-rc.5**。沿用原有布局、控件尺寸、间距、字体、字号、滚动和窗口拖动区域。通过原生插件管理器安装，不修改 DSH 应用程序或 ASAR。

## 本版外观

- 主界面增加灰黑顶条、Rahoo 等高线背景、底部 HARNESS 描边字标及细线斜纹。等高线和大字标只出现在空白会话页。
- 输入框增加 L 形角线、底部工具区分色、按钮斜切和禁用态斜纹。焦点角线短促揭示，装饰不拦截输入或点击。
- 侧栏选中项增加边缘标记与扫入效果；设置页、菜单、插件列表统一为工业面板、细线和斜纹细节。
- 启动画面突出 **DEEPSEEK HARNESS**，第二行描边，与等高线及斜纹呼应；1 秒结束后移除自身节点。日常动效由操作触发，不持续循环。

深浅模式均可用，跟随系统可用。Saira 字体只用于启动字标，正文使用 DSH 原字体。保留错误、警告、成功和代码增删的原语义颜色。系统减少动效时跳过启动动画并关闭新增过渡。

## 使用与回退

安装来源为冻结目录：

`/Users/alooshy/Documents/ChatGPT/forDSH/releases/dsh-skin-local-0.2.0`

运行期间保留此目录，后续开发修改 `dist/` 不会影响桌面当前版本。

在 **插件 → dsh-skin-local → 关闭开关** 中停用即可恢复原外观。v0.1.0 冻结包仍保留；如需退回旧版，可卸载当前皮肤，再添加 `releases/dsh-skin-local-0.1.0`，退出并重开 DSH。

若以后无法进入界面，先退出 DSH，再执行：

```sh
python3 /Users/alooshy/Documents/ChatGPT/forDSH/scripts/disable-skin.py
```

回退脚本保存原配置备份，仅取消此皮肤加载，不删除会话、账号或其他插件。

## 每版发布门槛

1. 更新源码与版本，运行 `scripts/build.py`、`scripts/check.py`。
2. 完成真实 DSH 布局、交互、停用、冷启动验证，并核对实际样式内容哈希。
3. `scripts/release.py --candidate` 冻结候选包。
4. 在原生桌面安装冻结包，核查实际生效、输入、主题、停用恢复与再次启用。
5. `scripts/release.py` 在全部证据匹配后生成 ZIP 和校验报告。

检查器限制宿主布局与字体属性；装饰伪元素仅允许绝对定位且必须不拦截事件。发布脚本拒绝旧哈希证据、布局变化、缺失检查和覆写冻结版本。
