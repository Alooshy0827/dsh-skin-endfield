# Endfield 皮肤 v0.1.0

适用已实测的 DeepSeek Harness Desktop **0.2.1-rc.5**。通过 DSH 自带插件管理器加载；不修改应用安装目录或 ASAR。

## 设计

- 母题：终末地式工业界面，纸白／炭黑底色与酸黄强调。
- 结构：沿用 DSH 的位置、尺寸、字体和间距；用直角、细线和主按钮斜切改变外观。
- 动效：1 秒 DEEPSEEK HARNESS 字标揭示，日常按钮过渡 140 ms；系统减少动效时跳过启动动画。

主界面继续采用用户自己的字号、字体与主题偏好。Saira 只用于启动字标。错误、警告、成功、代码增删差异沿用 DSH 的语义色。动画不抢焦点，不截获点击，不锁定滚动，结束后删除自身节点。

未使用游戏角色图片。此前从 Endfield Wiki 收集的素材保留在参考库，本版运行时没有引用它们。实际嵌入的图片只有用户授权的 Rahoo local 透明斜纹与微噪点；字标和网格为新写的 CSS/文字。素材来源与校验值记录在 `skin/assets/manifest.json`；Saira 随附 OFL 字体许可。运行时无外部素材请求。

测试过程中，故意停止后端时仍连接着的旧测试标签页产生了 DSH 会话/远程调用取消日志；服务就绪后新开标签页为零错误。旧日志另存 `old-tab-reconnect-diagnostics.json`，不将其算作正常冷启动的无错误记录。首次插件页布局对比受到点击屏幕下方开关导致的自动滚动影响；最终同一滚动位置的对比无差异。

## 使用与回退

本版已通过原生插件管理器安装并启用，安装来源为冻结目录：

`/Users/alooshy/Documents/ChatGPT/forDSH/releases/dsh-skin-local-0.1.0`

此目录是 DSH 本地链接包的实际来源，使用期间保留它。可在 **插件 → dsh-skin-local** 的开关中停用，立即恢复原有外观。关闭后也可通过该插件详情页卸载。

如果软件以后无法正常进入界面，可先退出 DSH，再运行以下命令，仅取消本皮肤的加载，并保存原配置备份：

```sh
python3 /Users/alooshy/Documents/ChatGPT/forDSH/scripts/disable-skin.py
```

重新打开 DSH 即恢复原皮肤。回退脚本不会删除会话、账号或其他插件。

## 每版发布门槛

1. 修改 `skin/`，更新包版本及客户端版本标记；不要覆盖已冻结的版本目录。
2. 运行 `python3 scripts/build.py` 和 `python3 scripts/check.py`。检查器限制非外观属性、字体和布局变量，保留语义状态色，并执行生命周期测试。
3. 在隔离的真实 DSH 中安装该构建，核对布局、主题、输入、卸载和冷启动，将当前哈希对应的证据保存至 `qa/v<版本>/runtime.json`。
4. `python3 scripts/release.py --candidate` 冻结候选包，用它进行原生桌面验证，保存同一哈希的 `desktop.json`。
5. `python3 scripts/release.py` 重新检查并生成正式 ZIP 和校验报告；缺少验证、哈希变化、布局差异或未通过的检查都会阻止发布。

DSH 升级时重新执行准备和接口复核，再更改 `engines.dsh`；不能沿用旧验证记录。
